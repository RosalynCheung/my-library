# My Library 

A personal library management system built with Python, SQLite and Streamlit.  

## 📖 About 
I built this project to manage my personal book collection. It supports both regular books and magazines.

## 🛠️ Tech Stack
- Python
- SQLite
- Streamlit

## ✅ Features
- [x] Database with ISBN unique constraint
- [x] CLI (library.py) for CRUD
- [x] Web UI (app.py) with Streamlit
- [x] Support for magazines (issue date & subtitle)
